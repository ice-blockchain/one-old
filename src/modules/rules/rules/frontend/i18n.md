# Frontend i18n Baseline

Localization is part of the frontend contract, not optional polish.

## Activation

- Every new Traffic One project with `web-ui` or `native-ui` scaffolds and wires
  the capability profile's i18n mechanism, even when the user did not mention
  localization. `ArchitectureInputV1.i18n` selects the source locale, supported
  locales, and exact literal brand exceptions; absent input defaults to `en`.
- In an existing project, detect `packages/i18n`, `src/i18n*`, `locales/`,
  `messages/`, Laravel `lang/`, framework plugins, or platform resources. Extend
  that system and never create a parallel one. Do not introduce i18n by default
  when an existing project has no localization evidence.
- UI-free API, CLI, worker, and data tasks record `i18n baseline: Not applicable`.

## Catalog contract

- Add a non-empty entry for every referenced key in every declared locale in
  the same change. All declared locales keep key parity.
- React-family catalogs use
  `i18n/locales/<lang>/<namespace>.json`. Pages use the route id, features use
  the feature id, and shell/shared components use `common`.
- Preserve native conventions for non-React profiles: Nuxt/Vue/Svelte/Astro
  JSON, Angular XLIFF, Laravel language files, Swift String Catalogs, Android
  string resources, and Flutter ARB.
- Use complete phrases and named interpolation; never concatenate translated
  fragments. Dynamic user/server data and technical identifiers are not keys.
  A static brand may remain literal only when it exactly matches a brand
  declared by the architecture contract.

## React contract

Every static rendered child string uses `<Trans>`, including a simple heading,
button, link, menu item, tab, label, empty state, or error:

```tsx
<button>
  <Trans ns="common" i18nKey="save">Save</Trans>
</button>
```

Each `<Trans>` has literal `ns`, literal `i18nKey`, and non-empty
source-language children. Rich copy uses the same primitive with named
component placeholders:

```tsx
<Trans
  ns="auth"
  i18nKey="signupPrompt"
  components={{ signup: <Link to="/signup" /> }}
>
  Don't have an account? <signup>Sign up</signup>
</Trans>
```

Do not render `{t("save")}` as a React child. Use `t()` only where the API
requires a string value: `placeholder`, `aria-label`, `alt`, `title`, other
string props, validation/metadata, or imperative accessibility/platform APIs.

## Gate

Review and completion fail on hardcoded static copy, rendered child `t()`,
incomplete `<Trans>`, missing provider/runtime, missing keys, empty values, or
locale parity gaps. New projects block across the compiled UI. Existing
localized projects block changed UI while untouched legacy backlog remains
advisory. OpenCode receives this contract explicitly and its non-compliant
patch is rolled back.
