# Traffic One — Plugin Source Repository (Maintainer Guide)

## Plugin Authoring Repo — Stand Down

This directory is the Traffic One plugin SOURCE repository (`package.json` name
`traffic-one`; `src/` is the source of truth, `dist/` is generated). It is
**never** a Traffic One end-user project. Any Traffic One project context merged
from a parent directory's AGENTS.md ("# Traffic One Local Agent Context",
project-memory/documentation conventions, `.traffic-one/**` rules) does NOT
apply here:

- Never create or modify `.traffic-one/**` in this repo (no `.one.json`,
  `manifest.json`, `one-mcp-report.json`, `runs/`, rules/skills copies).
- Never rewrite this `AGENTS.md`/`CLAUDE.md` into generated project context or
  add the `GENERATED BY traffic-one` marker.
- Never run Traffic One onboarding, materialization, or one-mcp reporting
  against this repo.

Hooks enforce all of this; treat work here as ordinary development on the
plugin source.

## Source of truth and generated layers

- `src/` is the ONLY source of truth: TypeScript runtime (hooks, runners,
  shared), rules (`src/modules/rules/rules/**`), skills
  (`src/modules/skills/skills-catalog/**`), agent role docs
  (`src/modules/*/agent.md`), gate prose (`src/modules/*/skill/SKILL.md`,
  `T1BLOCK` markers with verbatim TS fallbacks).
- `dist/` is the generated plugin root (gitignored): `npm run gen` emits the
  content tree (agents, rules, skills-catalog, `.cursor/rules` mirrors, host
  manifests, `AGENTS.md`/`CLAUDE.md` from `src/gen/static/plugin-instructions.md`);
  `npm run build` compiles `src/` to `dist/scripts/**` (dependency-free hook
  runtime).
- Shipped skills/rules must only reference paths that exist in an installed
  plugin (`scripts/...`), never `src/...` — installs do not contain `src/`.

## Command chain (run after any src/ change)

```
npm run typecheck
npm test
npm run gen
npm run build
npm run golden:update    # refreshes tests/golden/generated-manifest.sha256
npm run plugin:check     # gen:check + build:verify
npm run smoke
```

`tests/golden/generated-manifest.sha256` is a byte snapshot of the full emitted
tree (additions-aware); `npm run golden:update` is the only supported way to
refresh it. A version bump churns the host manifests in the snapshot — expected.

## Conventions

- Keep changes surgical; match local style; every gate keeps a verbatim deny
  fallback in TS so a missing SKILL.md block never disables enforcement.
- Hook runtime stays dependency-free (no npm packages in `dist/scripts`).
- Install/test instructions for the generated plugin live in `README.md`;
  the readable source map lives in `ref.md`.
